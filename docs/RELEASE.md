# iOS 7 Safari · Android v7.0

一个致敬 iOS 7 Safari 的玩具浏览器。纯 Kotlin + 原生 View，**1.7MB**，调用系统 WebView。

## 这个版本能做什么

**任务视图（主菜）**
- 点标签按钮，**当前网页本身**塌成带俯角的倒梯形卡片，落进卡片堆 —— 不是缩略图动画，是真实像素逐条带透视绘制
- 一屏 4 张，越远越小；标题条像打印纸一样"吐"出来
- 点卡片拉伸回整页；左滑删除跟手；长按拖动换位像两块木板互换
- 滚出屏幕缩到 1/9；拖到尽头整摞橡皮筋让位 + 3D 俯身

**浏览器**
- 和 Safari 几乎一样的 UI：44dp 顶底栏、0.5dp 发丝线、蓝色胶囊地址栏、全 Canvas 绘制的图标
- 往上一滑，顶栏 44→24dp、底栏压到 0，一起淡出；网页**不重排**，只做整数像素平移
- 任意网页双指放大（改写 viewport，但保留网站原本的版式）
- 起始页 9 宫格磁贴、搜索建议、书签 / 阅读列表 / 历史、iOS 分享面板、隐私模式
- 边缘右滑后退 / 左滑前进、自定义惯性、长按链接菜单、错误页、进度条

## 安装

下载下面的 `iOS7Safari-7.0.apk`，允许"安装未知来源应用"即可。

- 要求 Android 8.0（API 26）及以上
- 这是 **debug 签名**的构建（同一个调试密钥），从源码自己编一遍更放心：
  ```bash
  ./gradlew assembleDebug
  ```
- 首次打开如果提示"未知来源"，在系统设置里给文件管理器/浏览器授权即可
