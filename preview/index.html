已复刻的 iOS 7 Safari 细节

  • 20pt 状态栏（信号点 / 运营商 / Wi-Fi / 时间 / 电池）+ 44pt 顶栏
  • 统一「智能搜索框」：圆角 5pt、浅灰底、网址只显示一级域名
  • 顶栏底部 2.5dp 蓝色加载进度条，加载中右侧变停止叉
  • 44pt 底栏：五个按钮等距分布（各占 1/5 宽，图标居中），iOS 7 蓝色描边图标
  • 下滑收起顶栏与底栏，上滑或回到顶部自动展开
  • 标签页视图：3D 卡片栈 —— 真实透视倾角（rotationX + cameraDistance），越往上倾角越大、越小；可拖动，滑动时卡片连续穿过「最前」焦点位并实时重算透视
  • 进出场动画：进场卡片从当前页位置扇形展开、逐张错峰；退场选中卡片放大回页面、其余收拢淡出；关闭卡片向左飞出、下方卡片滑上补位
  • 书签面板三段切换：书签 / 阅读列表 / 历史记录
  • 私密浏览模式下顶栏底栏变深灰、图标转白、停止记录历史
  • 左右边缘滑动前进后退；长按链接可新标签打开 / 拷贝

技术实现

  • 渲染内核就是系统 android.webkit.WebView，未内置任何浏览器引擎
  • UA 设为 iPhone iOS 7.0.2 Safari，网站会返回移动端 / iOS 版页面
  • Kotlin + 原生 View，无第三方 UI 框架，minSdk 26
